隱私權政策

最後更新：2026-10-31

簡單說：本機器人只儲存伺服器管理員設定的內容；成員的名稱與頭像只在加入或離開的當下用來畫圖與發訊息，不會被存起來，也不會讀取聊天內容。

1. 適用範圍

本政策說明迎賓客 WCB（以下稱「本機器人」）在 Discord 伺服器中如何處理資料。本機器人由 Project :]（以下稱「營運者」）提供。使用或邀請本機器人，即表示你了解本政策。

2. 處理哪些資料

2.1 會儲存的資料（伺服器設定）

這些是伺服器管理員透過指令設定的內容：

  • 伺服器 ID、歡迎與離開頻道的 ID、自動身分組的 ID；
  • 歡迎與離開訊息的文字、樣式、是否啟用歡迎圖片；
  • 管理員上傳的自訂背景圖（只保留裁切後的版本）；
  • 「管理名單」中被允許使用設定指令的成員 ID 與身分組 ID。

2.2 成員加入或離開時暫時處理、但不儲存的資料

  • 成員的使用者 ID、帳號名稱、顯示名稱與頭像；
  • 伺服器名稱與目前成員人數。

這些資料只用來產生當下的歡迎或離開訊息、歡迎圖片和發放身分組。頭像只在記憶體中用來畫圖，畫完即丟棄。

2.3 操作與診斷紀錄

主機的運作日誌可能記錄伺服器 ID 與名稱、指令名稱、錯誤訊息與時間，用來排除故障。日誌不包含聊天訊息內容，保存時間依託管平台的設定。

2.4 營運者專用紀錄

營運者可封鎖特定伺服器，封鎖名單會記錄該伺服器的 ID 與名稱。

2.5 本機器人不做的事

  • 不讀取一般聊天訊息的內容（未使用 Message Content 權限）；
  • 不儲存成員名單、加入與離開的歷史紀錄或頭像；
  • 不追蹤成員行為，不用於廣告，不出售或交換資料。

3. 使用目的

資料只用於提供本機器人的功能：發送歡迎與離開訊息、產生歡迎圖片、發放自動身分組、判斷誰可以使用設定指令、維持服務運作與排除故障、防止濫用。

4. 儲存位置與第三方服務

本機器人使用下列服務，各服務有自己的隱私權政策，其伺服器也可能位於台灣以外的地區：

  • Discord：機器人透過 Discord 取得事件與發送訊息。
  • Turso：雲端資料庫，儲存第 2.1 項的伺服器設定。
  • Render 與 Wispbyte：執行機器人的主機，會處理第 2.2 項的暫時資料。

為了互相備援與分擔畫圖，兩台主機之間可能傳送頭像、顯示名稱、伺服器名稱與成員人數，請求帶有簽名以防冒用。

5. 保存期間與刪除

  • 伺服器設定會保存到管理員移除或要求刪除為止。
  • 機器人被移出伺服器後，設定預設不會自動刪除，方便重新邀請時沿用。如需刪除，請聯絡營運者。
  • 管理員可隨時用 /管理員 清空 清除管理名單，用 /歡迎 圖片 還原預設背景，或停用各項功能。
  • 刪除要求會在合理時間內處理，通常為 30 天內。

6. 資料安全

金鑰與權杖放在主機的環境變數中，不寫在程式碼裡。與 Discord、Turso 的連線使用加密連線。兩台主機之間的請求有簽名驗證，但若該主機未提供加密連線，內容就不一定加密。網路傳輸與電子儲存無法保證絕對安全，我們會盡合理努力保護資料。

7. 你的選擇與權利

  • 伺服器管理員可以隨時調整設定、停用功能或把機器人移出伺服器。
  • 任何成員都可以聯絡營運者，詢問或要求刪除與自己有關的資料。除了管理名單中的使用者 ID 之外，本機器人不儲存成員的個人資料。

8. 兒童

Discord 要求使用者至少滿 13 歲（或當地法律規定的年齡）。本機器人不會刻意蒐集兒童的資料。

9. 政策變更

政策變更時會更新本頁的「最後更新」日期。重大變更後繼續使用本機器人，視為接受新的政策。

10. 聯絡方式
